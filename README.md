# Wastewater & SARI Monitoring Austria

Interactive dashboard displaying virus load in Austrian wastewater, Sentinel virus detections, and SARI hospital admissions.

**Live Demo:** https://pasrom.github.io/wastewater/

## Features

### Map by Bundesland
- Choropleth of SARI admissions per 100,000 by region of residence, on a fixed scale per virus
- One marker per AGES treatment plant with its 4-week wastewater trend (AGES method, computed in the browser), sized by connected population equivalents
- Virus toggle (SARS-CoV-2, Influenza, RSV) and a week slider; the two newest SARI weeks are hatched as provisional
- Table view of every Bundesland and plant, including each plant's catchment (served agglomerations)

### Time Window
- One control in the page header ("Saison / 1 Jahr / Alles") sets the window of every time chart; the default is the last 12 months, "Saison" starts on 1 September
- The slider under each chart still zooms freely; "Zurücksetzen" returns to the chosen window

### Wastewater Monitoring
- Virus load of SARS-CoV-2, Influenza or RSV, one virus at a time on its own scale
- Location selector for individual treatment plants
- Interactive hover tooltips

### Sentinel Virus Detections (MedUni Wien)
- Stacked bar chart of virus detections by type
- Einsendungen (submissions) as a background area on the same count axis as the detections
- Heatmap of virus types over time
- Interactive time range slider

### SARI Hospital Admissions
- Stacked bar chart by diagnosis (COVID-19, Influenza, RSV, Pneumokokken, Sonstige)
- Filter by Bundesland and station type (Normal/Intensiv)
- Reporting delay indicator

### Demographics (Age/Gender)
- Grouped bar chart showing admissions by age group and gender
- Toggle between absolute numbers and per 100k population
- Time range slider for period selection

### Age Group Heatmap
- Heatmap visualization of admissions over time by age group
- Filter by diagnosis type
- Identifies infection wave patterns across age groups

## Data Sources

| Data | Source |
|------|--------|
| Wastewater | [AGES Abwasser-Monitoring](https://abwasser.ages.at) |
| Sentinel | [MedUni Wien Virusepidemiologie](https://viro.meduniwien.ac.at/forschung/virus-epidemiologie-2/ueberwachung-der-zirkulation-respiratorischer-viren-in-oesterreich/) |
| SARI Hospital | [SARI-Dashboard](https://www.sari-dashboard.at) |
| Map boundaries | Statistik Austria, prepared by [Flooh Perlot](https://github.com/ginseng666/GeoJSON-TopoJSON-Austria) (CC BY 4.0) |
| Plant sites and catchments | [EEA UWWTD reporting](https://water.europa.eu/freshwater/countries/uwwt) (EEA re-use policy) |

The files in `geo/` are generated by `tools/build_geo.py` from those two sources and keep
their licences. The boundaries are changed from the upstream file: coordinates
rounded to four decimals and feature properties renamed (`iso` → `code`).
`tools/verify_map.py` recomputes the map's numbers independently.

## Local Development

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080
